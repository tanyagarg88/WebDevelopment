# CSS Box Model

Every HTML element is represented as a rectangular box.

```css
.card {
    box-sizing: border-box;
    margin: 1.5rem;
    padding: 1rem;
    border: 1px solid #e2e8f0;
    border-radius: 8px;
}
```
