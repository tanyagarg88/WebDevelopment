# Anatomy of an HTML5 Document

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document Title</title>
</head>
<body>
  <header><h1>Welcome</h1></header>
  <main><p>Core content goes here.</p></main>
</body>
</html>
```
