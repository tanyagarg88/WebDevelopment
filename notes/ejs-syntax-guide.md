# Embedded JavaScript (EJS) Templating Guide

## Core Tags
- `<%= value %>`: Output escaped value to HTML.
- `<%- htmlString %>`: Output unescaped raw HTML.
- `<% jsCode %>`: Scriptlet tag for control flow (`if`, `for`).
- `<%- include('partials/navbar') %>`: Include reusable partial template.
