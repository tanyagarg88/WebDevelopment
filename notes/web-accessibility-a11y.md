# Web Accessibility (A11Y) Best Practices

- **Color Contrast**: Minimum 4.5:1 ratio for standard text (WCAG AA).
- **ARIA Attributes**: `aria-label`, `aria-expanded`, `aria-hidden` when semantic HTML isn't sufficient.
- **Keyboard Navigation**: Ensure all interactive elements have visible `:focus-visible` styles.
- **Form Labels**: Always pair `<label for="id">` with `<input id="id">`.
