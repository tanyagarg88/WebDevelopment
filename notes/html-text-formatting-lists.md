# HTML Text Formatting, Headings & Lists

- Headings: `<h1>` through `<h6>`
- Paragraphs and line breaks: `<p>`, `<br>`, `<hr>`
- Text emphasis: `<strong>`, `<em>`, `<mark>`, `<code>`
- Ordered & Unordered lists: `<ol>`, `<ul>`, `<li>`
- Definition lists: `<dl>`, `<dt>`, `<dd>`
