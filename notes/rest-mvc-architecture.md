# MVC Architecture Pattern in Express.js

- **Models**: Business logic and database schemas (`models/`)
- **Views**: UI templates rendered by EJS (`views/`)
- **Controllers**: Request handling and response coordination (`controllers/`)
- **Routes**: Endpoint definitions delegating to controllers (`routes/`)
