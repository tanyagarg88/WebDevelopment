# How the Web Works: Client-Server Architecture

- **Client**: Web browser sending HTTP/HTTPS requests.
- **Server**: Web host processing requests and returning HTML/CSS/JS.
- **DNS (Domain Name System)**: Resolves domain names to IP addresses.
- **TCP/IP & HTTP Protocols**: Fundamental communication layers.
