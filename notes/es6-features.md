# ES6+ Modern JavaScript Features

- **Arrow Functions**: Concise syntax and lexical `this` binding.
- **Destructuring**: Convenient unpacking of arrays and objects.
- **Spread/Rest Operators**: `...` operator for copying and variable arguments.
- **Template Literals**: Multi-line strings with string interpolation `${expr}`.
- **Optional Chaining & Nullish Coalescing**: `user?.profile?.name ?? 'Anonymous'`.
